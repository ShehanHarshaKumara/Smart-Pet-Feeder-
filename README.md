## 📌 Project Overview

The **Smart Pet Feeder** is an IoT-enabled food and water dispensing system. It allows pet owners to schedule feeding times, dispense food and water automatically, and control the device using a mobile app.

## ✨ Key Features

- 🍖 Automatic food dispensing
- 💧 Automatic water supply
- 📱 Mobile app control
- 🔥 Firebase Realtime Database
- 📡 Wi-Fi control using NodeMCU ESP8266
- ⏰ Scheduled feeding
- 🛠 Manual feed and water control

## 🧩 Hardware Components

| Component | Purpose |
|---|---|
| NodeMCU ESP8266 | Main controller with Wi-Fi |
| Servo Motor | Food dispensing control |
| Water Pump Motor | Water supply control |
| Relay Module | Controls motor power |
| Food Container | Stores dry pet food |
| Water Tank | Stores water |
| Breadboard Power Supply | Stable power for circuit |

## 🧠 System Architecture

```mermaid

    A[Flutter Mobile App] --> B[Firebase Realtime Database]
    B --> C[NodeMCU ESP8266]
    C --> D[Servo Motor]
    C --> E[Relay Module]
    E --> F[Water Pump Motor]
    D --> G[Food Bowl]
    F --> H[Water Bowl]
⚙️ Working Process
User sets feeding schedule in the mobile app.
Schedule data is stored in Firebase.
NodeMCU reads data through Wi-Fi.
Servo motor dispenses food.
Water pump fills the water bowl.
Device status updates in the mobile app.
📱 Mobile App Functions
Add feeding schedule
Manual food dispense
Manual water dispense
View next meal time
Monitor feeder status
